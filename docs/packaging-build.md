# Packaging & build tooling

## Chosen tools

| Purpose | Tool | Why |
|---------|------|-----|
| Live image builder | `live-build` (Debian) | Canonical, well-documented, `SOURCE_DATE_EPOCH` support, clean chroot + binary stages. |
| Base OS bootstrap | `debootstrap` | Builds Debian Stable minimal rootfs from archive; reproducible. |
| Bootloader | GRUB 2 (BIOS + UEFI) | `grub-pc` + `grub-efi-amd64`; live-build handles both. |
| ISO authoring | `xorriso` + `grub-mkrescue` (via live-build) | Hybrid ISO, bootable on BIOS and UEFI. |
| Chroot packaging | `.deb` from Debian archives + custom `mlite-*` packages | Standard Debian packaging for custom shell. |
| Installer | Calamares (optional, graphical) OR `debian-installer` minimal | Calamares recommended for polished install UI; lightweight CLI fallback included. |
| Default apps | Debian Stable repos (see package lists) | All DFSG-free; clear `debian/copyright`. |

## live-build configuration layout

`config/` follows standard `live-build` semantics:

```
config/
  archives/           # apt sources (bookworm main, +security, optional non-free-firmware)
  bootloaders/        # grub config + EFI/BIOS boot entries
  hooks/              # live-build hooks (normalize, cleanup, service tuning)
  includes.chroot/    # files copied into the live rootfs (config, desktop files, systemd units)
  includes.binary/    # files copied into the ISO (boot, firmware, docs)
  package-lists/      # .list files of packages to install
  auto/               # generated by `lb config` (build config)
```

### Key live-build options (`scripts/build-iso.sh`)

```bash
lb config \
  --architectures amd64 \
  --linux-flavours amd64 \
  --mode debian \
  --distribution bookworm \
  --archive-areas "main contrib non-free-firmware" \
  --bootappend-live "boot=live components quiet splash" \
  --bootloader grub \
  --grub-splash "$PWD/assets/wallpapers/grub-bg.png" \
  --iso-application "macOS-Lite" \
  --iso-publisher "macOS-Lite Project" \
  --iso-volume "macOS-Lite" \
  --memtest none \
  --security true \
  --updates true \
  --backports false \
  --source false \
  --firmware-chroot false \
  --firmware-binary false \
  --compression xz \
  --xorriso-boot-grub-device-hd0 /dev/sda
```

Non-free firmware is **off by default** (100% DFSG-free live image). A separate `config-nonfree` variant can be generated for Wi-Fi/GPU firmware.

Custom `mlite-*` packages are built as Debian packages (`dpkg-buildpackage` or `debuild`) and dropped into `config/package-lists/` via a local `deb` mirror directory `config/includes.chroot/etc/apt/sources.list.d/macos-lite.list` pointing to `file:///...` during build, or installed directly from `config/includes.chroot/root/debs/`.

## Reproducible-build considerations

- `SOURCE_DATE_EPOCH` exported in `scripts/build-iso.sh` (fixed timestamp, e.g. the release tag date).
- `live-build` normalizes file mtimes in the chroot.
- SquashFS `xz` uses deterministic options (`-Xbcj x86 -b 1M`, no timestamps).
- GRUB `mkrescue` output is deterministic given identical inputs.
- Build runs in a clean container pinned to `debian:bookworm`; apt sources pinned to `bookworm` + `bookworm-security` (no `updates` rolling).
- The ISO + `SHA256SUMS` + `.sig` are published; consumers verify reproducibility by rebuilding and comparing SHA-256.

## Default apps & package selection rationale

Tiered profiles in `config/package-lists/`:

- `core.list` — bootable base, no desktop.
- `desktop.list` — Wayfire + shell + default apps.
- `apps.list` — optional end-user apps (firefox-esr, gedit, thunar, viewnior, etc.).

The default ISO installs `core + desktop + apps`. Users can install `core` only for a minimal system.

## Installer

**Primary:** Calamares (`calamares`) with a macOS-Lite branding module (slideshow, original wallpaper, no Apple assets). Calamares is the standard lightweight graphical installer used by many distros.

**Fallback/advanced:** `debian-installer` (text) included on the ISO for expert installs.

Both target the installed system (not just live). Post-install, `macos-lite-firstboot` hook configures user, autologin, and zram.
